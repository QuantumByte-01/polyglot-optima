02 / 02
Training Workflow

GRPO-based reinforcement learning loop using TRL/Unsloth against the live OpenEnv server.

1
Problem Sampling
Curriculum-Gated Problem Selection
The dataset loader draws Python functions from HumanEval and a synthetic bank. Difficulty axes are frozen per episode from the adaptive curriculum state. With 15% probability, an adversarial trap is injected with category-weighted resampling from recent failure modes.
SourceHumanEval + synthetic bank
Trap rate~15% of episodes
Hardware1 of 8 profiles sampled
2
Episode Rollout
3-Round Iterative Refinement
The agent receives the Python function + hardware profile via env.reset(), then executes up to 12 tool calls across 3 rounds. Each round the agent may profile, compile, verify, and adjust strategy. Only the Round 3 submit_optimization call triggers reward computation.

3
Reward Computation
Composable Reward DAG
At episode end, five rubrics are evaluated and summed with learned weights. Rewards are continuous — no hard 0/1 cliff. The Roofline-aware speedup score normalises performance relative to the hardware's compute/memory bound. Trap episodes gate reward on anti-gaming verification.
Speedup · speedup / roofline_ceiling · continuous 0→1
Correctness · fuzz pass rate · rtol per function
Diagnosis · reasoning trace vs ground-truth bottleneck
Portability · compile pass across x86 / ARM / RISC-V
Self-Correction · speedup delta round-over-round
4
Policy Update
GRPO via TRL + Unsloth
Episode trajectories are batched and passed to Group Relative Policy Optimization (GRPO). The reasoning trace inside <think>…</think> blocks is treated as a latent RL signal — the DiagnosisRubric scores whether the trace correctly identifies the bottleneck. Unsloth provides memory-efficient fine-tuning with LoRA adapters.
AlgorithmGRPO (group relative)
FrameworkTRL + Unsloth LoRA
Signal<think> trace scored
5
Curriculum Update
Adaptive 4-Axis Difficulty Adjustment
After each training batch, the adaptive curriculum increments or decrements each difficulty axis based on recent episode outcomes. Axes advance when the rolling success rate exceeds threshold; trap category weights are resampled toward recent failure modes to prevent memorization.
AxisRangeAdvance condition
function_tier0 → 3Correctness rate > 0.75 over last 20 eps

fuzzer_strictness0 → 2Fuzz pass rate > 0.8

↻ Loop back to Step 1 — new episodes sampled at updated difficulty axes until training budget exhausted
